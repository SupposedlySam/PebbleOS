# FFI Bridge Architecture

This document describes how Flutter watchfaces communicate with Pebble firmware using Dart FFI (Foreign Function Interface).

## Overview

```
┌─────────────────────────────────────────────┐
│          Flutter Watchface (Dart)            │
│  - UI rendering                              │
│  - Business logic                            │
│  - Time formatting                           │
└──────────────┬──────────────────────────────┘
               │
               │ Dart API
               │
┌──────────────▼──────────────────────────────┐
│      WatchfacePlatform (Dart)                │
│  - High-level Dart API                       │
│  - Type conversion                           │
│  - Memory management                         │
└──────────────┬──────────────────────────────┘
               │
               │ Dart FFI
               │
┌──────────────▼──────────────────────────────┐
│      WatchfaceNativeBindings (Dart FFI)      │
│  - C function bindings                       │
│  - Native type definitions                   │
└──────────────┬──────────────────────────────┘
               │
               │ C ABI
               │
┌──────────────▼──────────────────────────────┐
│      Watchface API (C)                       │
│  src/fw/flutter_bridge/watchface_api.c       │
└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│      Pebble Firmware (C)                     │
│  - Display driver                            │
│  - Button handlers                           │
│  - Tick service                              │
└──────────────────────────────────────────────┘
```

## Files

### Dart Side (Flutter Watchface)

- **`lib/src/platform/watchface_platform.dart`**
  - High-level Dart API
  - Manages callbacks and memory
  - Type conversions between Dart and C
- **`lib/src/platform/ffi_bindings.g.dart`** (auto-generated)
  - Low-level FFI bindings
  - Generated by ffigen from C header
  - Native struct definitions
  - Function signature bindings

### C Side (Pebble Firmware)

- **`src/fw/flutter_bridge/watchface_api.h`**
  - C API header
  - Struct definitions
  - Function declarations
- **`src/fw/flutter_bridge/watchface_api.c`**
  - C API implementation
  - Callback management
  - Integration with firmware

## Generating FFI Bindings

The FFI bindings are auto-generated using [`ffigen`](https://pub.dev/packages/ffigen), which parses the C header and generates type-safe Dart code.

### Generate Bindings

```bash
cd flutter_watchface
dart run ffigen
```

This reads the configuration from `pubspec.yaml`:

```yaml
ffigen:
  name: WatchfaceNativeBindings
  description: "Auto-generated bindings for Pebble watchface C API"
  output: "lib/src/platform/ffi_bindings.g.dart"
  headers:
    entry-points:
      - "../src/fw/flutter_bridge/watchface_api.h"
```

### When to Regenerate

Regenerate bindings whenever you modify:

- `src/fw/flutter_bridge/watchface_api.h` - Add/remove/change functions or structs
- Any struct definitions or function signatures

The generated file (`ffi_bindings.g.dart`) should **never be manually edited**. It's auto-generated from the C header, which is the single source of truth.

### What Gets Generated

From the C header, ffigen generates:

- **Struct definitions** - `WatchfaceDisplaySpecs`, `WatchfaceFrameData`, etc.
- **Function bindings** - `watchface_get_display_specs()`, `watchface_send_frame()`, etc.
- **Callback typedefs** - `watchface_time_tick_callback`, etc.
- **Helper types** - All the necessary type mappings for FFI

## Communication Patterns

### 1. Flutter → Firmware (Host API)

Flutter calls C functions directly via FFI.

#### Example: Getting Display Specs

**Dart side:**

```dart
final platform = WatchfacePlatform.instance;
final specs = platform.getDisplaySpecs();
print('Display: ${specs.width}x${specs.height}');
```

**FFI binding:**

```dart
final getDisplaySpecs = lib
    .lookup<ffi.NativeFunction<GetDisplaySpecsNative>>('watchface_get_display_specs')
    .asFunction<GetDisplaySpecsDart>();
```

**C side:**

```c
WatchfaceDisplaySpecs watchface_get_display_specs(void) {
    WatchfaceDisplaySpecs specs;
    specs.width = 144;
    specs.height = 168;
    specs.color_depth = 8;
    specs.dpi = 175;
    specs.is_color = true;
    return specs;
}
```

#### Example: Sending Frame

**Dart side:**

```dart
Uint8List pixels = renderWatchface();
platform.sendFrame(pixels, 144, 168, 1);
```

**C side:**

```c
int32_t watchface_send_frame(const WatchfaceFrameData* frame) {
    // Copy to display framebuffer
    compositor_set_framebuffer(frame->pixels, frame->width, frame->height);
    display_refresh();
    return 0;
}
```

### 2. Firmware → Flutter (Callbacks)

Firmware calls Dart functions via registered callbacks.

#### Example: Time Tick

**C side triggers event:**

```c
void on_tick_timer(void) {
    int64_t time_ms = get_current_time_ms();
    watchface_trigger_time_tick(time_ms);
}
```

**Bridge calls Dart:**

```c
void watchface_trigger_time_tick(int64_t timestamp_ms) {
    if (g_on_time_tick != NULL) {
        WatchfaceTimeData time;
        time.timestamp_ms = timestamp_ms;
        g_on_time_tick(&time);  // Calls into Dart
    }
}
```

**Dart receives callback:**

```dart
platform.onTimeTick = (DateTime time) {
  setState(() {
    _currentTime = time;
  });
};
```

## Data Type Mapping

| Dart Type      | FFI Type                 | C Type        |
| -------------- | ------------------------ | ------------- |
| `int`          | `@ffi.Int32()`           | `int32_t`     |
| `int` (64-bit) | `@ffi.Int64()`           | `int64_t`     |
| `bool`         | `@ffi.Bool()`            | `bool`        |
| `double`       | `@ffi.Double()`          | `double`      |
| `Uint8List`    | `ffi.Pointer<ffi.Uint8>` | `uint8_t*`    |
| `String`       | `ffi.Pointer<ffi.Utf8>`  | `const char*` |

## Memory Management

### Dart → C (sendFrame)

```dart
bool sendFrame(Uint8List pixels, ...) {
  final framePtr = calloc<WatchfaceFrameDataNative>();  // Allocate
  final pixelsPtr = calloc<ffi.Uint8>(pixels.length);   // Allocate

  try {
    // Copy data
    pixelsPtr.asTypedList(pixels.length).setAll(0, pixels);
    framePtr.ref.pixels = pixelsPtr;

    // Call C
    _bindings.sendFrame(framePtr);
  } finally {
    // Always free!
    calloc.free(pixelsPtr);
    calloc.free(framePtr);
  }
}
```

### C → Dart (callbacks)

C must keep data valid during the callback:

```c
void watchface_trigger_time_tick(int64_t timestamp_ms) {
    WatchfaceTimeData time;  // Stack allocation - valid during callback
    time.timestamp_ms = timestamp_ms;
    g_on_time_tick(&time);   // Dart must copy data if needed
}
```

## Initialization Sequence

### 1. Firmware Startup

```c
int main(void) {
    // Initialize firmware
    display_init();
    button_init();
    tick_service_init();

    // Initialize Flutter bridge
    watchface_initialize();

    // Start main loop
    while (1) {
        process_events();
    }
}
```

### 2. Flutter Initialization

```dart
void main() {
  // Initialize platform
  final platform = WatchfacePlatform.instance;

  if (!platform.initialize()) {
    print('Failed to initialize platform');
    return;
  }

  // Register callbacks
  platform.onTimeTick = (time) => print('Tick: $time');
  platform.onButtonEvent = (event) => print('Button: $event');

  // Run Flutter app
  runApp(MyWatchface());
}
```

## Performance Considerations

### Frame Rendering

- **Target: 30 FPS** (33ms per frame)
- Flutter rendering: ~10-15ms
- FFI call + memory copy: ~2-5ms
- C compositor: ~5-10ms
- Display refresh: ~5-10ms

### Optimizations

1. **Reduce FFI calls** - batch updates when possible
2. **Reuse buffers** - don't allocate on every frame
3. **Partial updates** - only send changed regions
4. **Hardware acceleration** - use DMA if available

## Troubleshooting

### "Library not found"

The Dart code can't find the C library:

```dart
// Try different library names/paths
try {
  return WatchfaceNativeBindings(
    ffi.DynamicLibrary.open('libpebble_watchface.so')
  );
} catch (e) {
  // Fallback to embedded symbols
  return WatchfaceNativeBindings(ffi.DynamicLibrary.process());
}
```

### "Symbol not found"

The C function isn't exported:

```c
// Ensure functions are not static and have C linkage
#ifdef __cplusplus
extern "C" {
#endif

// Your functions here

#ifdef __cplusplus
}
#endif
```

### Memory corruption

Check pointer lifetimes:

```dart
// BAD: Pointer freed before C can use it
final ptr = calloc<Data>();
_bindings.asyncCall(ptr);
calloc.free(ptr);  // Freed too early!

// GOOD: Keep alive until callback completes
final ptr = calloc<Data>();
_bindings.syncCall(ptr);
calloc.free(ptr);  // Safe to free now
```
